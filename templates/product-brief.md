# Product brief

## Intent
State the target user, situation, problem, current alternative, desired result, and the source of each claim. Separate facts from assumptions.

## First useful version
Describe one complete user task. List included behavior, non-goals, constraints, and the smallest test of value. State which high impact unknown must be resolved first.

## Evidence
For each source: ID, origin, date, statement, sample, and limits. Mark generated personas and forecasts as hypotheses. Record real user observations only when they occurred.

## Outcome
Define the measure, baseline, target, cohort, time window, data source, and keep/change/stop rule. Explain why the measure represents user value.

## Commercial path, if applicable
State the initial audience, positioning, acquisition route, pricing hypothesis, activation, support model, cancellation, and unit cost. Identify evidence still needed.

## Decision
State the chosen next change, rejected alternative, reason, owner, and unresolved choices.
