# Security and privacy review

## Scope and assets
Link the change, affected users, data, trust boundaries, identities, and external services. State what is outside the review.

## Threats and controls
For each plausible threat: entry path, affected asset, possible loss, existing control, required change, and check. Include access and tenant boundaries, abuse, secrets, dependencies, and tool or prompt injection where relevant.

## Data lifecycle
Map collection, use, storage, sharing, export, deletion, backups, and retention. State what can enter model context and what must remain in a controlled system.

## Evidence
Record the check, actual result, candidate identity, observer, and limits. Keep raw secrets and customer data out of the record.

## Residual risk
State unresolved risks, owner, rationale, and any required expert or user decision. A completed template is not certification or an authenticated approval.
