# Outcome and scale review

## Hypothesis
Link the original problem, target user, change, and release. State the expected value and disproof condition.

## Measurement
Record baseline, target, cohort, observation window, data source, sample, actual result, and limits. Separate correlation from a demonstrated cause.

## Product decision
Choose keep, change, expand, or stop. State the reason, evidence, non-goals, and next smallest experiment.

## Scale or cost change
Identify the measured constraint and current workload. Compare viable options. Define quality, failure behavior, unit cost, expected improvement, and validation method.

## Result
Record actual improvement or regression on the candidate, including recovery. Link new work to its evidence. Do not infer product value from code tests alone.
