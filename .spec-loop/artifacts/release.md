# Local source release

The user approved implementation of the installation/pilot milestone. Build the committed source with scripts/package.py, verify the extracted package with install_check --package and record the artifact digest. A local technical source-package release can be sealed under CHG-006 after acceptance and operational evidence pass. It does not install a host, deploy a product, publish a marketplace or fulfill CHG-HOST. Deliver the implementation through a reviewed GitHub branch. Preserve the prior package and records for recovery.
